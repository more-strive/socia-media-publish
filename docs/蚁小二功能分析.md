# 蚁小二（yixiaoer.cn）功能点分析

> 分析方式：官网营销文案 + Web 端前端 bundle（路由 / API / UI 文案）交叉验证
> 入口：https://www.yixiaoer.cn/web（SPA，需登录；已下载 index/vendor bundle 提取功能清单）

## 一、产品定位

一站式**自媒体矩阵运营中台**。官方口号："矩阵管理、一键发布、AI 视频创作、数据统计、指纹浏览器全搞定"。
目标用户：MCN 机构、企业新媒体团队、矩阵运营工作室。
覆盖链路：**内容生产 → 多平台分发 → 粉丝互动 → 数据复盘 → 团队协作**。

## 二、核心功能模块

### 1. 一键分发（核心卖点）
- 视频 / 图文 / 文章多平台一键发布
- 批量分发：1 个视频 → 多个账号；多个视频 → 1 个账号
- 微信公众号多账号发布（走开放平台 API）
- 浏览器 RPA 发布（无开放平台网站的自动化兜底方案）
- 网络区域（IP 归属地）设置发布、App 云发布
- 定时发布、发布日历 / 日程、发布前审核流（审核员、审核设置）
- 平台级细节：封面 / 比例裁剪、摘要、原创声明、合集、标签、分类

### 2. AI 视频创作
- Seedance 2.0 生成爆款短视频（积分 / 额度计费）
- 数字人：克隆数字人、真人出镜、虚拟形象、声音克隆与训练
- 素材混剪、口播 / 新闻播报模板
- AI 自动字幕 / 标题 / 特效

### 3. 智能发布助手
- 浏览器插件对接可灵、即梦、海螺、Vidu 等 AI 创作平台
- AI 生成作品一键勾选，云发布到抖音、小红书
- OpenClaw 本地 AI 伙伴（本地部署，自动执行发布任务）
- 蚁小二专属技能一键安装

### 4. 账号托管 + 指纹浏览器
- 多平台账号授权托管（国内平台 + TikTok / YouTube 等海外平台）
- 指纹环境隔离（依赖本地桌面客户端连接）
- 代理 IP 管理、连通性检测
- 云窗口（cloud window）、账号分组、运营人 / 负责人指派
- 失效账号批量检测与一键重新授权

### 5. 私信评论管理
- 抖音、视频号私信 / 评论统一收件
- 关键词自动回复、欢迎语规则
- 个人话术 / 话术库（分组管理）
- 多级评论嵌套、监控账号（watch accounts）

### 6. 数据统计
- 账号数据、作品数据、汇总数据
- 负责人维度分析、排行详情
- 汇总数据定时推送飞书 / 钉钉
- 数据导出、内容报表

### 7. 内容创作辅助
- 长文编辑器（Slate，支持 DOCX 批量导入）
- 小红书文章生成（模板 + AI）
- AI 文案生成（接入火山方舟 Ark 大模型）

### 8. 团队协作
- 团队 / 成员 / 分组 / 席位管理
- 角色权限、链接邀请成员、管理员设置
- 发布审核流配置、操作日志导出

### 9. 商业化与账户体系
- 套餐订阅、续费、升级、席位 / 流量包购买
- 微信免密支付（papay）代扣、渠道礼品
- 发票申请、批量开票、PDF 下载
- 登录方式：密码 / 验证码、微信扫码、钉钉

## 三、技术栈线索（前端 bundle 分析）

| 维度 | 结论 |
|---|---|
| 构建 | Vite + React，按 media / editor / dnd / chart 拆包 |
| 编辑器 | Slate 富文本（长文编辑器） |
| 验证 | 阿里云验证码 |

| AI 集成 | 火山引擎：方舟 Ark（AI 文案）、Seedance（视频生成） |
| 客户端 | 配套桌面端（指纹环境需本地客户端在线） |

## 四、观察小结

1. 本质是"生产 → 分发 → 互动 → 数据"全链路中台，差异化壁垒在**指纹浏览器 + RPA**，可覆盖没有开放平台的网站。
2. AI 能力（数字人、Seedance、OpenClaw）是近期重点演进方向，独立走积分 / 额度计费。
3. 商业化成熟：席位订阅 + 增值包 + 免密支付代扣 + 发票体系，典型的 B 端 SaaS 打法。

## 附录：桌面端 4.14.22 逆向实证（REA，2026-10-27）

> 工具：REA（github.com/morluto/rea）`analyze-javascript-application` + 手工解包 `app.asar`。
> 样本：`D:\Program Files\yixiaoer`（蚁小二4.0 v4.14.22，Electron + React 19，pnpm monorepo：packages/main、preload、renderer）。
> 渲染层 dist 内**无业务页面**——客户端是多标签浏览器 Shell，业务 UI 全在云端 `www.yixiaoer.cn/web`，经 socket.io（`lj.yixiaoer.cn`）与本地 WS（127.0.0.1:30020-30030）双向驱动。

### 1. 架构要点（复刻参照）

- Tab 即 `WebContentsView`（sandbox/contextIsolation），分区策略：首页 `persist:default-session`、账号授权 `persist:auth-{accountId}`、RPA 发布 `tab-{tabId}`（用完即毁）、指纹环境 `persist:fingerprint-{environmentId}`
- RPA 脚本从服务端热更（electron-store `rapData` → `vm.runInThisContext` 执行；reptile 平台 API 模块同样热替换），客户端本体只是加载器
- 登录成功检测：`webContents.debugger` attach → CDP `Fetch.enable`（按平台 XHR URL pattern 拦响应）→ `Fetch.getResponseBody` 判定字段（如快手 `creator/pc/home/userInfo` 判 `coreUserInfo`、B 站 `x/passport-login/web/cookie/info`、小红书 `/galaxy/creator/home/personal_info`、百家号 `builder/app/appinfo`），注册表 `platformMapsIn` 含 43 个 watcher
- 文本注入 `webContents.insertText` + `sendInputEvent(Enter)`；文件注入 CDP `DOM.setFileInputFiles`（getDocument depth:-1 + pierce）；发布按钮 XPath 文案组 发布→发表→发布作品→发 布→立即投稿
- 话题预处理（description 内 `<topic text="x">` 标签）：抖音 `#x `（>5 个不再拼）、微博 `#x#`、快手/视频号 `___!!!!___x`、B 站/头条/百家号剔除、小红书 `#x`+Enter
- 授权回传：`POST {API}/webhook/web`（authResult/hostedSiteSync，附 cookie+localStorage 快照）；发布状态枚举 uploading/uploadFail/uploadSuccess/pushing/pushFail/pushSuccess
